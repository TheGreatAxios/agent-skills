# Blueprints: VPN And Proxy Abuse Controls

## Goal
Reduce abuse from anonymous/proxy networks while limiting user friction.

## Strategy
1. Observe in `DRY_RUN`.
2. Segment by route risk level.
3. Enforce `LIVE` on high-risk write paths first.
