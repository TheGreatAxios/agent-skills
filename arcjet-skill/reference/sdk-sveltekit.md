# SDK SvelteKit

## Install
`npm i @arcjet/sveltekit @arcjet/inspect`

## Minimal example
```ts
import arcjet from "@arcjet/sveltekit";
```

## Production variant
- Keep server-only instance in `/src/lib/server` and enforce in `handle` or endpoints.
